Module 1: Lists and loops

A list stores many values under one name. A loop repeats the same code for each value. Together, they let your code work with any number of items.

Review: key ideas

Lists. A list stores values in order. Each value has a position, called an index. The first index is 0. The last index is len(numbers) - 1.

numbers = [3, 7, 2, 9]
print(numbers[0])     # 3
numbers[1] = 10       # change the second value
numbers.append(5)     # add a value to the end
print(numbers)        # [3, 10, 2, 9, 5]

Loops. A for loop runs the same code once for each item. It stops by itself after the last item.

for n in numbers:
    print(n)               # each number, one per line

for i in range(len(numbers)):
    print(i, numbers[i])   # the index and the value

for i, n in enumerate(numbers):
    print(i, n)            # the same thing, a shorter way

Common patterns. You can add up values, search for a value, or build a new list. The % sign gives the remainder after dividing, so n % 2 == 0 means n is even.

numbers = [3, 7, 2, 9]

total = 0                  # 1. add up
for n in numbers:
    total += n
print(total)               # 21

found = False              # 2. search
for n in numbers:
    if n == 9:
        found = True
print(found)               # True

evens = []                 # 3. build a new list
for n in numbers:
    if n % 2 == 0:
        evens.append(n)
print(evens)               # [2]

Watch out for:

  • Off-by-one errors. range(len(numbers) + 1) goes one step past the end of the list, so numbers[i] causes an IndexError.
  • Changing a list while you loop over it. Removing items inside the loop can make the loop skip items. Build a new list instead, like evens above.
  • Empty lists. numbers[0] fails if the list is empty. Think about what your code should do when there are no items.

Module 2: Functions

A function is a named block of code that does one job. It takes inputs, called parameters, and sends back a result with return. Functions let you write code once and use it many times.

Review: key ideas

Parameters and return values. The inputs of a function are called parameters. The return line sends a result back to the code that called the function. A function with no return gives back None.

def add(a, b):
    return a + b

result = add(3, 4)    # a is 3, b is 4
print(result)         # 7

Scope. A variable made inside a function is a local variable. It only exists while the function runs. If you need the value outside the function, return it.

def square(x):
    squared = x * x   # local variable
    return squared

print(squared)        # NameError: squared only exists inside square()

Break a problem into steps. When code gets long, split it into small functions. Each function does one clear step, and you can test each one by itself. This is called decomposition.

def get_average(nums):
    return sum(nums) / len(nums)

def is_passing(avg):
    return avg >= 60

avg = get_average([70, 85, 55])
print(is_passing(avg))   # True

Watch out for:

  • Printing instead of returning. print() only shows a value on the screen. return gives the value back, so other code can use it.
  • Using variables from outside the function. Pass the values in as parameters instead.
  • Using the same name inside and outside a function. They are two different variables, which can be confusing.
  • Changing a list that was passed in. If a function changes a list, the change stays after the function ends.

Module 3: Object-oriented basics

Object-oriented programming is a way to keep data and the actions that use that data together. You already use objects: "hello".upper() and my_list.append(5) call methods on objects. In this module, you make your own.

Review: key ideas

Classes. A class is a plan for making objects. It lists the data each object stores, called attributes, and the actions it can do, called methods. A method is a function that belongs to a class.

class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{self.name} says woof!")

my_dog = Dog("Luna")
my_dog.bark()         # Luna says woof!
  • __init__ is the constructor. It runs each time you make a new object.
  • self means “this object.” self.name is the name stored in this dog.
  • An f-string, like f"{self.name} says woof!", puts the values inside { } into the text.

Each object has its own data. This data is called the object’s state. Changing one object does not change another one.

dog1 = Dog("Luna")
dog2 = Dog("Rex")
dog1.name = "Nova"
print(dog1.name)      # Nova
print(dog2.name)      # Rex

Methods can change state. Each Counter below keeps its own value.

class Counter:
    def __init__(self):
        self.value = 0

    def increment(self):
        self.value += 1

a = Counter()
b = Counter()
a.increment()
a.increment()
print(a.value)        # 2
print(b.value)        # 0

Watch out for:

  • Forgetting self. Every method needs self as its first parameter: def increment(self):, not def increment():. Inside a method, use self.value to reach the object’s data.
  • Forgetting the parentheses. my_dog.bark() runs the method. my_dog.bark without () does not.
