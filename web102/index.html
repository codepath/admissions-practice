On this page, each game has four properties. name is the name of the game. pledged is how much money people have promised to give so far, in dollars. goal is how much money the game needs, in dollars. backers is how many people have promised to give money. In the full project, each game also has a description and an image.

Review: key ideas

Objects. An object stores related values together. Each value has a name, called a property. Use a dot to read a property.

const game = {
  name: "Cube Monster",
  pledged: 29446,
  goal: 20000,
  backers: 321
};
console.log(game.name);      // Cube Monster
console.log(game.backers);   // 321

A list of objects. GAMES_JSON is an array: a list of values in order. Each value in it is one game object. Each value has a position, called an index. The first index is 0.

console.log(GAMES_JSON.length);    // 11
console.log(GAMES_JSON[0].name);   // Heroes Of Mythic Americas

Loops. A for...of loop runs the same code once for each game. In Challenge 3, you use a loop to make one card for each game.

for (const game of GAMES_JSON) {
  console.log(game.name);   // each name, one per line
}

Template literals. A template literal is a string inside backticks (`), not quotes. JavaScript replaces each ${...} with a value.

const game = GAMES_JSON[0];
const text = `${game.name} has ${game.backers} backers.`;
console.log(text);   // Heroes Of Mythic Americas has 9 backers.

The page (the DOM). The DOM (Document Object Model) is how JavaScript sees the elements on a web page. In the full project, you use it to find elements, make new ones, and add them to the page. An element inside another element is called its child.

const gamesContainer = document.getElementById("games-container");
const card = document.createElement("div");   // make a new div
card.classList.add("game-card");              // give it a class
card.innerHTML = `<h3>${game.name}</h3>`;     // put HTML inside it
gamesContainer.appendChild(card);             // add it to the page

Numbers for the stats section

At the top of the Sea Monster website, three cards show numbers about all the games: the total number of contributions, the total money raised, and the number of games. In Challenge 4, you find the first two numbers with reduce(). The number of games is GAMES_JSON.length.

Review: key ideas

Arrow functions. An arrow function is a short way to write a function. These two functions do the same thing:

function addOne(n) {
  return n + 1;
}

// the same function, written as an arrow function
const addOneArrow = (n) => n + 1;

reduce(). reduce() visits each item in a list and combines all the items into one value. You give it two things: a function, and a start value. The function gets the result so far (here called total) and the next item. It returns the new result.

const nums = [5, 10, 20];
const sum = nums.reduce((total, n) => total + n, 0);
console.log(sum);   // 35

// step by step: 0 + 5 = 5, then 5 + 10 = 15, then 15 + 20 = 35

With a list of objects, add one property from each object:

const games = [{ goal: 100 }, { goal: 400 }];
const allGoals = games.reduce((total, game) => total + game.goal, 0);
console.log(allGoals);   // 500

Numbers with commas. On the website, big numbers have commas, like 1,234,567. The method toLocaleString() adds them: (1234567).toLocaleString("en-US") gives "1,234,567". The tests on this page only check the number, so you do not need toLocaleString() here.

Watch out for:

  • Forgetting the start value. Without the 0 at the end, reduce() uses the first item as the start. With a list of objects, the result is wrong. With an empty list, it causes an error.
  • Using GAMES_JSON inside your function. The tests also call your function with other, smaller lists. Use the parameter games instead. A parameter is an input of a function. Here, games is the list that the tests pass in to your function.
  • Printing instead of returning. console.log() only shows a value. The tests check the value that your function returns.

Funded and unfunded games

The website has three buttons. They show only the unfunded games, only the funded games, or all the games. In Challenge 5, you use filter() to find the unfunded games and the funded games. Use this rule for every question on this page:

The ruleA game is unfunded when pledged < goal.
A game is funded when pledged >= goal. So a game that reaches its goal exactly is funded.
Review: key ideas

filter(). filter() makes a new array with only the items that you want to keep. You give it a function that returns true (keep the item) or false (do not keep it). The items stay in the same order.

const nums = [4, 15, 8, 23];
const big = nums.filter((n) => n > 10);
console.log(big);    // [15, 23]
console.log(nums);   // [4, 15, 8, 23] (filter() does not change the original array)

With a list of objects, check a property of each object:

const popular = GAMES_JSON.filter((game) => game.backers >= 1000);
// the games with 1000 backers or more

Comparisons. < means “less than.” >= means “greater than or equal to.” > without the = is false when the two numbers are equal.

On the website. Each button has an event listener: code that waits for a click, then runs a function. For example, filterUnfundedOnly() first removes all the game cards with deleteChildElements(). Then it adds cards for the unfunded games only.

Watch out for:

  • Returning names instead of games. These questions ask for the game objects. The tests compare the whole objects.
  • Curly braces without return. An arrow function with curly braces needs the word return: (game) => { return game.backers >= 1000; }. Without curly braces, it returns the value by itself: (game) => game.backers >= 1000.

Describe the company

At the top of the website, a short text describes Sea Monster Crowdfunding. In Challenge 6, you add a sentence about the unfunded games. First you count them. Then you build the sentence with a template literal and the ternary operator.

Review: key ideas

Counting with filter(). The length of an array is the number of items in it. So if you use filter() and then .length, you get the number of items that match.

const nums = [4, 15, 8, 23];
const count = nums.filter((n) => n > 10).length;
console.log(count);   // 2

The ternary operator. The ternary operator is a short if...else that gives back a value. It has three parts: a condition, a value for when the condition is true, and a value for when it is false.

// condition ? valueIfTrue : valueIfFalse
const backers = 1;
const word = backers === 1 ? "backer" : "backers";
console.log(`${backers} ${word}`);   // 1 backer

The ternary line does the same job as this code:

let word;
if (backers === 1) {
  word = "backer";
} else {
  word = "backers";
}

Template literals. Use ${...} to put values into one sentence. Remember the backticks (`).

const count = 3;
const text = `There are ${count} new games.`;
console.log(text);   // There are 3 new games.

Watch out for:

  • Zero. In English, use the plural with 0: “0 games,” not “0 game.” Use the singular only when the count is exactly 1.
  • Small differences. The tests compare the whole sentence. The spaces, the capital letters, and the period must match exactly.

Top two games

The website also shows the two games with the most money pledged. In Challenge 7, the starter code sorts the games for you. Then you use destructuring to get the first two. Here, you write the sort yourself.

Review: key ideas

Sorting with a compare function. sort() puts the items of an array in order. To sort numbers or objects, give it a compare function. The function gets two items, a and b. If it returns a negative number, a goes first. If it returns a positive number, b goes first.

const nums = [20, 5, 90];
nums.sort((a, b) => b - a);
console.log(nums);   // [90, 20, 5] (highest first)

sort() changes the original array. To keep the original list the same, sort a copy. The spread operator (...) makes a copy of an array:

const nums = [20, 5, 90];
const sorted = [...nums].sort((a, b) => b - a);
console.log(sorted);   // [90, 20, 5]
console.log(nums);     // [20, 5, 90] (not changed)

Destructuring. Destructuring copies items from an array into variables, in one line.

const colors = ["red", "green", "blue"];
const [first, second] = colors;
console.log(first);    // red
console.log(second);   // green

In the full project, you also put ... inside the destructuring. Question 2 asks what it does there.

Watch out for:

  • Sorting the original list. sort() changes the list that you call it on. In the full project, the starter code sorts GAMES_JSON itself. On this page, the tests pass other lists to your function, and they check that those lists do not change. So sort a copy.
  • The order of a and b. a - b sorts from lowest to highest. b - a sorts from highest to lowest.
