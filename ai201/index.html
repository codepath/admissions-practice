Coding and Prompt Writing

The placement assessment has two parts: solving a coding problem, and writing a clear prompt for an AI tool. This page practices both, using the two examples from the AI201 candidate guide. The coding problems on this page use Python. On the assessment, you can use Python or Java for the coding problem. The first time you run code, the page loads a Python checker. This can take a few seconds.

  1. Solve each problem. Some ask you to write code. Others ask about a prompt.
  2. Check your answer. For code, the page runs small tests and shows which ones did not pass.
  3. Stuck? Get a hint. After a hint, you can see the answer.
About AI toolsWhile you practice, you may ask an AI tool to explain an idea, or to test a prompt you wrote. But AI tools are not allowed on the real placement assessment, so make sure you can write the code and the prompt on your own.

Coding: the imbalance problem

This is the coding example from the candidate guide. It can look hard at first, but you can solve it in small steps. Most steps are one short function. Test each step on small examples before you go to the next one.

On the assessment, your code is tested on many lists, not only the example. So also try short lists, lists with negative numbers, lists with the same number more than once, and lists where the best number to remove is the first or the last one.

The problemYou are given a list of integers (whole numbers, like 7, 0, or −3). The imbalance of the list is the sum of the absolute differences between all adjacent pairs. You may remove exactly one element (one item) from the list. Find the smallest possible imbalance after you remove one element.

Input: [4, 1, 6, 3, 8]
Output: 10
Removing 6 gives [4, 1, 3, 8]. Its imbalance is |4 − 1| + |1 − 3| + |3 − 8| = 3 + 2 + 5 = 10.
Review: key ideas

Adjacent pairs. Two items are adjacent when they are next to each other in a list. A list with 5 items has 4 adjacent pairs. To visit each pair, loop over the indexes and stop one step before the end.

nums = [4, 1, 6, 3, 8]
for i in range(len(nums) - 1):
    print(nums[i], nums[i + 1])

# 4 1
# 1 6
# 6 3
# 3 8

Absolute difference. The absolute difference of two numbers is the distance between them. It is never negative. In math, it is written with two lines, like |1 − 6|. In Python, use abs().

print(abs(4 - 1))    # 3
print(abs(1 - 6))    # 5, not -5

A new list without one item. To skip the item at index i without changing the original list, build a new list. You can use a loop, or you can use slices. A slice like nums[a:b] gives the items from index a up to, but not including, index b. If you leave out a, the slice starts at the beginning. If you leave out b, it goes to the end. So nums[:i] is the items before index i, and nums[i + 1:] is the items after it.

nums = [4, 1, 6, 3, 8]
i = 2

# 1. with a loop
rest = []
for j in range(len(nums)):
    if j != i:
        rest.append(nums[j])
print(rest)    # [4, 1, 3, 8]

# 2. with slices
rest = nums[:i] + nums[i + 1:]
print(rest)    # [4, 1, 3, 8]

# nums did not change
print(nums)    # [4, 1, 6, 3, 8]

Try every choice. The problem lets you remove any one element. A simple and correct way to solve it is to try each choice, find the result, and keep the smallest one. This is like finding the smallest number in a list.

Watch out for:

  • Going past the end of the list. With range(len(nums)), the last step reads nums[i + 1], which does not exist. Python stops with an IndexError.
  • Changing the list that was passed in. pop() and remove() change the list itself, so later steps use the wrong list. Build a new list instead.
  • Skipping by value instead of by index. A list can have the same number more than once. In [3, 7, 3, 1], index 2 is the second 3. Skip only the item at index i, not every item that has the same value.
  • Starting the smallest value at 0. No imbalance is smaller than 0, so the answer would always be 0. Start with a real result instead.

Prompt writing: the salon voicemails

The second part of the assessment asks you to write a system prompt. A system prompt is the set of instructions an AI tool gets before it reads the input. On the assessment, your prompt is tested on several inputs, not only the example. So the output needs the exact same format every time.

This page has no AI model, so it cannot run or test a prompt. Instead, the questions below check the ideas behind a strong prompt. At the end, you write your own prompt.

The taskA hair salon gets voicemails from customers who want to book an appointment. You get a written copy of each voicemail, called a transcript. Write a system prompt that tells an AI tool to find the customer’s name, the date and time they want, and their phone number. The AI should return these details as a reservation record, in the same format every time.
Example input“Hi, this is Jordan calling — I’d love to book an appointment on May 14th around 2pm if possible. You can reach me at 555-0192. Thanks!”
Example outputName: Jordan
Date: 05/14
Time: 2:00 PM
Contact: 555-0192
Review: key ideas

One prompt, many inputs. You write the system prompt once. It must work for every voicemail, not only the example. So your prompt should not name Jordan or May 14th. It should give rules that work for any customer.

Be specific. Say what the AI will read, what to find, and what to return. “Get the booking details” is not specific. “Find the customer’s name, the date and time they want, and their phone number” is specific.

Show the exact output format. Give the labels, their order, and the format for each value. Use a template. A template is a pattern with an empty place for each value. Here, the parts in [ ] show what goes in each place:

Name: [the customer's name]
Date: [MM/DD, like 05/14]
Time: [H:MM AM or PM, like 2:00 PM]
Contact: [phone, like 555-0192]
  • MM/DD means two digits for the month, a slash, then two digits for the day.
  • H:MM AM or PM means the hour, a colon, two digits for the minutes, a space, then AM or PM.
  • Tell the AI to return only the record. If the AI adds extra words, like “Sure! Here is your record:”, the output does not match the format.

Plan for edge cases. An edge case is an unusual input that can break your prompt. Ask yourself: what could go wrong? For example:

  • A detail is missing, like no phone number.
  • The date is not a calendar date, like “next Tuesday.”
  • The time uses words, like “noon” or “around 4 in the afternoon.”
  • The voicemail has extra information, like a question or a second phone number.

Never guess. When a detail is missing, an AI tool may write something that sounds right but is not in the voicemail. Tell it what to write when a detail is missing or not clear.
